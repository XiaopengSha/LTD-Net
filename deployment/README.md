# 通用部署约定

本次发布支持 PyTorch checkpoint 与 ONNX Runtime CPU 推理。
主入口及命令见根目录 README 的 ONNX 部分。

| 项目 | 约定 |
| --- | --- |
| 输入颜色 | RGB，灰度/RGBA 图像先转换为 RGB |
| 缩放 | torchvision 双线性 Resize，antialias=True，默认 256×256 |
| 范围 | 转 float32，先除以 255，再归一化 |
| 均值 | 0.485, 0.456, 0.406 |
| 标准差 | 0.229, 0.224, 0.225 |
| 输入布局 | NCHW，固定 batch=1 |
| 输出 | 未经显示归一化的原始异常图 |
| 图像分数 | 原始异常图最大值 |

部署时必须保留教师、三个适配器、学生及多尺度差异计算。不要用 `light.py` 旧测速包装器
的输出或 FPS 代表完整推理；旧包装器只调用 teacher/student，遗漏适配器与异常图计算。
通用推理保存的热力图仅用于显示，不参与 AUROC/AUPRO，也不是可跨图片比较的置信度。

TensorRT、RKNN 转换和板端工程不在本次发布范围。将来集成时，先保存同一图片的预处理张量，
核对布局、归一化、完整异常图与图像分数，再使用完整测试集比较检测指标和实际延迟。
当前仓库没有可交付的公开模型下载地址；先训练或由维护者提供对应架构的 checkpoint。
